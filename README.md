# Flowr – Android build (no Android Studio needed)
First time:
1. Make a free account at github.com and create a new repository.
2. Upload EVERYTHING from this folder (including the hidden .github folder), commit.
3. Actions tab -> "Build APK" -> Run workflow (~5 min). Download "flowr-apk", unzip, install app-debug.apk.
Updating: replace www/index.html in your repository with the new one, then run the workflow again and install the new APK over the old one.
